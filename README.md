# Room Booking API

Командный проект курса «Разработка безопасного ПО», НИУ ВШЭ, 2026/2027.

Планируемый продукт — небольшой REST API бронирования переговорных на Python, FastAPI и SQLite. Первый выпуск `v1.0.0` рассчитан на локальную демонстрацию через Swagger с синтетическими данными.

Основной документ: [project.md](project.md). Он содержит паспорт, границы, риски, план безопасной разработки и проверок. Разделы результатов пока имеют статус «не выполнено».

## Текущий статус

Подготовлена документация. Исходный код, инструкции запуска и реальные результаты проверок появятся после создания рабочего каркаса. Репозиторий пока не содержит запускаемого продукта.

## План работы

1. Внести ФИО и учебные адреса участников с учётом видимости репозитория.
2. Создать минимальный API и зафиксировать исходное состояние `baseline-v0.1.0`.
3. Выполнить выбранные проверки, сохранить свидетельства и провести триаж.
4. Внести полезное улучшение и повторить проверку.
5. Дополнить `project.md`, индивидуальные страницы и инструкцию воспроизведения; принять решение о выпуске.
